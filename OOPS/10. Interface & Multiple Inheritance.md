An **interface** in Java is a reference type used to define a **contract** that classes must follow. It specifies _what a class must do_, but not _how it does it_. Interfaces help achieve **abstraction**, **multiple inheritance**, and **loose coupling** in Java.


# 1️ What is an Interface?

An interface:
- Contains **abstract methods** (by default)
- Can contain **constants**
- Cannot have constructors
- Cannot be instantiated
- Is implemented using the `implements` keyword
### Basic Syntax

```java


interface Animal {  
    void sound();   // abstract method  
}

Implementing an interface:

class Dog implements Animal {  
    public void sound() {  
        System.out.println("Bark");  
    }  
}



```
# 2️ Why Use Interface?

Interfaces are used for:
### 1. Abstraction
Hides implementation details and shows only functionality.
### 2. Multiple Inheritance

Java does not support multiple inheritance with classes, but it supports multiple inheritance with interfaces.

```java
interface A {  
    void methodA();  
}  
  
interface B {  
    void methodB();  
}  
  
class C implements A, B {  
    public void methodA() {}  
    public void methodB() {}  
}



```


# 3️ Features of Interface

|Feature|Description|
|---|---|
|Methods|Public and abstract by default|
|Variables|Public, static, and final by default|
|Multiple Inheritance|Supported|
|Constructors|Not allowed|
|Access Specifier|Must be public (for methods)|


# 4 Difference Between Interface and Abstract Class

|Interface|Abstract Class|
|---|---|
|Supports multiple inheritance|Does not support multiple inheritance|
|Only abstract methods (before Java 8)|Can have abstract + concrete methods|
|No constructors|Can have constructors|
|Variables are final by default|Can have non-final variables|
|Uses `implements`|Uses `extends`|

# 5 Marker Interface

An interface with **no methods** is called a marker interface.
Example:
- `Serializable`
- `Cloneable`

Used to indicate that a class has special behavior.


# 6 Functional Interface (Java 8)

An interface with **only one abstract method**.

Example:

```java

@FunctionalInterface
interface MyInterface {
    void run();
}
```

Used in **Lambda Expressions**.

Example:
```java

MyInterface obj = () -> System.out.println("Running");
obj.run();
```

# 7 Real-World Example
Think of an interface like a **remote control**
- It defines buttons (methods)
- TV decides how those buttons work
```java

interface Remote {
    void powerOn();
    void powerOff();
}

class TV implements Remote {
    public void powerOn() {
        System.out.println("TV is ON");
    }

    public void powerOff() {
        System.out.println("TV is OFF");
    }
}

```

# 8 When to Use Interface?
Use interface when:
- You want to achieve full abstraction
- You want multiple inheritance
- You want to define a contract for unrelated classes
- You are designing APIs
# 9 Important Points to Remember
- A class can implement multiple interfaces
- An interface can extend another interface
- Methods must be overridden as `public`
- You cannot create object of interface directly

# Example with Interface Inheritance
```java

interface Animal {
    void eat();
}

interface Dog extends Animal {
    void bark();
}

class Labrador implements Dog {
    public void eat() {
        System.out.println("Eating");
    }

    public void bark() {
        System.out.println("Barking");
    }
}

```

#### Multiple Inheritance in Java 
![[Pasted image 20250731102655.png]]

- **Multiple inheritance** means a class can inherit **features (methods)** from **more than one parent**.
```java
// Interface 1
interface Printable {
    void print();
}

// Interface 2
interface Showable {
    void show();
}

// Class implementing both interfaces
class Document implements Printable, Showable {
    public void print() {
        System.out.println("Printing document...");
    }

    public void show() {
        System.out.println("Showing document...");
    }
}

// Main class
public class Main {
    public static void main(String[] args) {
        Document d = new Document();
        d.print();  // Output: Printing document...
        d.show();   // Output: Showing document...
    }
}

```
