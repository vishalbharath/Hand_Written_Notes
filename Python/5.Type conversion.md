
# Type Casting in Python

**Last Updated:** 21 May 2026

Type Casting is the process of converting a value from one data type to another so that operations can be performed correctly.

There are two types of type casting in Python:

1. **Implicit Type Conversion**
2. **Explicit Type Conversion**

---

# Implicit Type Conversion

Implicit type conversion occurs when Python automatically converts one data type into another during an operation.

## Example

```python
# Python automatically converts 'a' to int
a = 7
print(type(a))

# Python automatically converts 'b' to float
b = 3.0
print(type(b))

# Result becomes float because one operand is float
c = a + b
print(c)
print(type(c))

# Result becomes float because multiplication involves float
d = a * b
print(d)
print(type(d))
```

**Output**

```text
<class 'int'>
<class 'float'>
10.0
<class 'float'>
21.0
<class 'float'>
```

### Explanation

- `a` is an integer.
- `b` is a float.
- When `a` and `b` are used together, Python converts the integer to a float automatically.
- The result of the operation is a float.

---

# Explicit Type Conversion

Explicit type conversion occurs when the programmer manually converts a value from one type to another using built-in functions.

Common type conversion functions:

| Function | Description |
|----------|-------------|
| `int()` | Converts a value to an integer |
| `float()` | Converts a value to a float |
| `str()` | Converts a value to a string |

---

# Convert Integer to Float

```python
a = 5
n = float(a)

print(n)
print(type(n))
```

**Output**

```text
5.0
<class 'float'>
```

---

# Convert Float to Integer

```python
a = 5.9
n = int(a)

print(n)
print(type(n))
```

**Output**

```text
5
<class 'int'>
```

### Note

`int()` removes the decimal portion (it does not round).

---

# Convert Integer to String

```python
a = 5

n = str(a)

print(n)
print(type(n))
```

**Output**

```text
5
<class 'str'>
```

---

# Convert String to Float

```python
a = "5.9"

n = float(a)

print(n)
print(type(n))
```

**Output**

```text
5.9
<class 'float'>
```

---

# Convert String to Integer

```python
a = "5"

n = int(a)

print(n)
print(type(n))
```

**Output**

```text
5
<class 'int'>
```

## Invalid Conversion

```python
b = "t"

print(int(b))
```

**Output**

```text
ValueError: invalid literal for int() with base 10: 't'
```

### Explanation

- `"5"` can be converted because it represents a number.
- `"t"` cannot be converted because it is not a numeric string.

---

# Adding a String and an Integer

Python does not allow arithmetic operations between incompatible data types.

## Incorrect Example

```python
a = 5
b = "7"

n = a + b
```

**Output**

```text
TypeError: unsupported operand type(s) for +: 'int' and 'str'
```

---

# Correct Example Using Type Casting

```python
a = 5
b = "7"

n = a + int(b)

print(n)
print(type(n))
```

**Output**

```text
12
<class 'int'>
```

### Explanation

The string `"7"` is first converted into the integer `7`, allowing the addition to succeed.

---

# Key Takeaways

- Type casting converts values from one data type to another.
- Python performs **implicit conversion** automatically when needed.
- **Explicit conversion** is done using functions like `int()`, `float()`, and `str()`.
- `int()` truncates the decimal portion of a float.
- Converting a non-numeric string to an integer raises a `ValueError`.
- Arithmetic operations require compatible data types.


|Conversion|Example|Result|
|---|---|---|
|`int("25")`|String → Integer|`25`|
|`float("3.14")`|String → Float|`3.14`|
|`str(100)`|Integer → String|`"100"`|
|`bool(0)`|Integer → Boolean|`False`|
|`bool(5)`|Integer → Boolean|`True`|
|`list("ABC")`|String → List|`['A','B','C']`|
|`tuple([1,2])`|List → Tuple|`(1,2)`|
|`set([1,1,2])`|List → Set|`{1,2}`|
|`complex(2,3)`|Complex Number|`(2+3j)`|


```python

# Original values
num_str = "123"
float_str = "45.67"
integer = 10
decimal = 99.99
text = "Python"
numbers = [1, 2, 2, 3]
pairs = [('name', 'Alice'), ('age', 25)]

# String to Integer
print("String -> Int:", int(num_str))

# String to Float
print("String -> Float:", float(float_str))

# Integer to Float
print("Int -> Float:", float(integer))

# Float to Integer (decimal part removed)
print("Float -> Int:", int(decimal))

# Integer to String
print("Int -> String:", str(integer))

# Boolean conversions
print("0 -> Bool:", bool(0))
print("100 -> Bool:", bool(100))
print("'' -> Bool:", bool(""))
print("'Hello' -> Bool:", bool("Hello"))

# String to List
print("String -> List:", list(text))

# List to Tuple
print("List -> Tuple:", tuple(numbers))

# List to Set (removes duplicates)
print("List -> Set:", set(numbers))

# List of pairs to Dictionary
print("Pairs -> Dict:", dict(pairs))

# Integer to Complex
print("Int -> Complex:", complex(integer))

# Implicit Type Casting
result = integer + decimal
print("Implicit Casting (int + float):", result)
print("Result Type:", type(result))

# User input type casting
age = int(input("Enter your age: "))
print("After 5 years, your age will be:", age + 5)
```
