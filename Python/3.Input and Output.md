
## Overview

- `input()` → Used to take user input.
- `print()` → Used to display output on the console.

---

# Taking Input with `input()`

## Syntax

```python
variable = input("Prompt message")
```

### Example

```python
name = input("Enter your name: ")
print("Hello,", name, "! Welcome!")
```

### Output

```text
Enter your name: GeeksforGeeks
Hello, GeeksforGeeks ! Welcome!
```

### Notes

- Returns input as a **string** by default.
- Useful for interactive programs.

---

# Printing Output with `print()`

## Syntax

```python
print(value)
```

### Example

```python
print("Hello, World!")
```

### Output

```text
Hello, World!
```

---

# Printing Variables

## Single Variable

```python
s = "Brad"
print(s)
```

### Output

```text
Brad
```

## Multiple Variables

```python
s = "Anjelina"
age = 25
city = "New York"

print(s, age, city)
```

### Output

```text
Anjelina 25 New York
```

### Notes

- Separate multiple values with commas.
- `print()` automatically adds spaces between values.

---

# Taking Multiple Inputs

## Using `split()`

```python
x, y = input("Enter two numbers: ").split()
print(x, y)
```

### Input

```text
10 20
```

### Output

```text
10 20
```

### Notes

- `split()` separates input based on spaces.
- Values are stored as strings unless converted.

---

# Type Casting User Input

Since `input()` returns a string, convert it when needed.

## Integer Input

```python
age = int(input("How old are you?: "))
```

## Float Input

```python
value = float(input("Evaluate 7/2: "))
```

### Example

```python
i = int(input("How old are you?: "))
f = float(input("Evaluate 7/2: "))

print(i, f)
```

### Output

```text
How old are you?: 23
Evaluate 7/2: 3.5

23 3.5
```

---

# Quick Reference

| Function | Purpose | Return Type |
|----------|---------|------------|
| `input()` | Take user input | `str` |
| `print()` | Display output | `None` |
| `int()` | Convert to integer | `int` |
| `float()` | Convert to decimal number | `float` |
| `split()` | Split input into multiple values | `list` |

---

# Key Points

- `input()` always returns a **string**.
- Use **type casting** (`int()`, `float()`, etc.) when numeric input is needed.
- `print()` can display strings, variables, and expressions.
- Multiple inputs can be taken in one line using `split()`.
- Multiple values can be printed together using commas.
