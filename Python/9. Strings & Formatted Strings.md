
## Introduction

A **string** is a sequence of characters enclosed within quotes. Strings are one of the most commonly used data types in Python and are used to store text.

```python
name = "Alice"
message = 'Hello, World!'
```

---

# Creating Strings

Python supports:

- Single quotes (`' '`)
- Double quotes (`" "`)
- Triple quotes (`''' '''` or `""" """`)

## Single and Double Quotes

```python
first_name = 'John'
last_name = "Doe"
```

## Triple Quotes (Multi-line Strings)

```python
text = """
This is a
multi-line string.
"""
```

---

# String Properties

## Strings are Immutable

Once created, a string cannot be modified directly.

```python
name = "Python"

# ❌ Error
# name[0] = "J"

# ✅ Create a new string
name = "J" + name[1:]
```

---

# Accessing Characters

## Indexing

```python
word = "Python"

print(word[0])   # P
print(word[1])   # y
print(word[-1])  # n
```

### Index Positions

| Character | P | y | t | h | o | n |
|-----------|---|---|---|---|---|---|
| Index     | 0 | 1 | 2 | 3 | 4 | 5 |
| Negative  | -6 | -5 | -4 | -3 | -2 | -1 |

---

# String Slicing

Syntax:

```python
string[start:end:step]
```

## Examples

```python
text = "Python Programming"

print(text[0:6])    # Python
print(text[7:])     # Programming
print(text[:6])     # Python
print(text[::2])    # Pto rgamn
print(text[::-1])   # Reverse string
```

---

# Common String Operations

## Concatenation

```python
first = "Hello"
second = "World"

result = first + " " + second

print(result)
# Hello World
```

## Repetition

```python
print("Hi! " * 3)

# Hi! Hi! Hi!
```

## Membership Operators

```python
text = "Python"

print("Py" in text)       # True
print("Java" not in text) # True
```

---

# Useful String Functions

## Length

```python
text = "Python"

print(len(text))
# 6
```

## Type Conversion

```python
age = 25

print(str(age))
# '25'
```

---

# Common String Methods

## Convert Case

```python
text = "python programming"

print(text.upper())
print(text.lower())
print(text.title())
print(text.capitalize())
```

### Output

```text
PYTHON PROGRAMMING
python programming
Python Programming
Python programming
```

---

## Remove Whitespace

```python
text = "   Python   "

print(text.strip())
print(text.lstrip())
print(text.rstrip())
```

---

## Replace Text

```python
text = "I like Java"

print(text.replace("Java", "Python"))
```

Output:

```text
I like Python
```

---

## Split String

```python
text = "apple,banana,mango"

fruits = text.split(",")

print(fruits)
```

Output:

```python
['apple', 'banana', 'mango']
```

---

## Join Strings

```python
fruits = ["apple", "banana", "mango"]

result = ", ".join(fruits)

print(result)
```

Output:

```text
apple, banana, mango
```

---

## Find Text

```python
text = "Python Programming"

print(text.find("Programming"))
print(text.find("Java"))
```

Output:

```text
7
-1
```

# Escape Sequences

| Escape Sequence | Meaning |
|----------------|----------|
| `\n` | New line |
| `\t` | Tab |
| `\\` | Backslash |
| `\'` | Single quote |
| `\"` | Double quote |

Example:

```python
print("Hello\nWorld")
print("Python\tProgramming")
```

Output:

```text
Hello
World

Python    Programming
```

---

# Raw Strings

Raw strings ignore escape sequences.

```python
path = r"C:\Users\Admin\Documents"

print(path)
```

Output:

```text
C:\Users\Admin\Documents
```

---

# Formatted Strings (f-Strings)

Introduced in Python 3.6, **formatted strings** provide a clean and readable way to embed variables and expressions inside strings.

Syntax:

```python
f"Text {variable}"
```

---

## Basic Example

```python
name = "Alice"
age = 22

print(f"My name is {name} and I am {age} years old.")
```

Output:

```text
My name is Alice and I am 22 years old.
```

---

## Expressions Inside f-Strings

```python
a = 10
b = 20

print(f"Sum = {a + b}")
print(f"Product = {a * b}")
```

Output:

```text
Sum = 30
Product = 200
```

---

## Formatting Numbers

### Decimal Places

```python
pi = 3.14159265

print(f"{pi:.2f}")
```

Output:

```text
3.14
```

---

### Width and Alignment

```python
name = "Python"

print(f"|{name:<10}|")  # Left
print(f"|{name:^10}|")  # Center
print(f"|{name:>10}|")  # Right
```

Output:

```text
|Python    |
|  Python  |
|    Python|
```

---

### Thousand Separator

```python
number = 1000000

print(f"{number:,}")
```

Output:

```text
1,000,000
```

---

### Percentage

```python
score = 0.85

print(f"{score:.1%}")
```

Output:

```text
85.0%
```

---

# Older Formatting Methods

## `%` Formatting

```python
name = "Alice"
age = 25

print("Name: %s, Age: %d" % (name, age))
```

---

## `str.format()` Method

```python
name = "Alice"
age = 25

print("Name: {}, Age: {}".format(name, age))
```

Named placeholders:

```python
print("Name: {n}, Age: {a}".format(n=name, a=age))
```

---

# String Comparison

```python
print("apple" == "apple")  # True
print("apple" != "Apple")  # True
print("apple" < "banana")  # True
```

Strings are compared lexicographically (dictionary order).

# Best Practices

✅ Use **f-strings** for modern Python code.

✅ Use meaningful variable names.

✅ Use triple quotes for multi-line text.

✅ Use string methods instead of manual text manipulation.

✅ Prefer `strip()` when handling user input.

❌ Avoid excessive string concatenation inside loops.

- Strings are immutable.
