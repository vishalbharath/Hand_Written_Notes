# Python Introduction

## Overview

Python is a **high-level programming language** known for its simple, readable, and beginner-friendly syntax. It is one of the most popular programming languages due to its versatility and ease of use.

## Key Features

- Clean and readable syntax.
- Allows writing programs with fewer lines of code.
- Supports multiple programming paradigms:
  - Object-Oriented Programming (OOP)
  - Functional Programming
  - Procedural Programming
- Dynamically typed language.
- Automatic garbage collection.
- Large standard library and ecosystem.
- Cross-platform compatibility.

## Applications of Python

Python is widely used in:

- 🌐 Web Development
- 🤖 Artificial Intelligence (AI)
- 📊 Data Analysis & Visualization
- 🔬 Machine Learning
- ⚙️ Automation & Scripting
- 🎮 Game Development
- ☁️ Cloud Computing
- 🔒 Cybersecurity
- 📱 Software Development

# Hello World Program

The **Hello World** program is traditionally the first program written when learning a new programming language. It demonstrates the basic structure of a Python program.

## Code

```python
# This is a comment. It will not be executed.
print("Hello, World!")
```

## Output

```text
Hello, World!
```

---

# Understanding the Code

## 1. Comments

```python
# This is a comment.
```

- Comments begin with `#`.
- Used to explain code.
- Ignored during program execution.

## 2. The `print()` Function

```python
print("Hello, World!")
```

- `print()` is a built-in Python function.
- Displays text or values on the screen.

### Syntax

```python
print(value)
```

### Example

```python
print("Python")
print(100)
```

Output:

```text
Python
100
```

## 3. Strings

```python
"Hello, World!"
```

- A **string** is a sequence of characters enclosed in quotes.
- Python supports both single and double quotes.

Examples:

```python
'Hello'
"Hello"
```

# Python Indentation

Unlike languages such as C, C++, and Java, Python uses **indentation** to define code blocks.

### Example

```python
if True:
    print("This line is indented.")
```

### Key Points

- Indentation is mandatory.
- Usually 4 spaces are used.
- Improper indentation causes errors.

Incorrect:

```python
if True:
print("Error")
```

Correct:

```python
if True:
    print("No Error")
```
