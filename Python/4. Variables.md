
# Python Variables


Variables are used to store data that can be referenced and manipulated during program execution. A variable is essentially a name assigned to a value.

Unlike Java and many other languages, Python variables do not require explicit declaration of type. The type of the variable is inferred from the value assigned.

## Example

```python
x = 5
name = "Alex"

print(x)
print(name)
```

**Output**

```text
5
Alex
```

---

# Rules for Naming Variables

- Names can contain letters, digits, and underscores (`_`).
- The first character cannot be a digit.
- Names are case-sensitive (`myVar` and `myvar` are different).
- Python keywords such as `if`, `else`, and `for` cannot be used as variable names.

## Valid Variable Names

```python
age = 21
_colour = "lilac"
total_score = 90
```

## Invalid Variable Names

```python
# Starts with a digit
1name = "Error"

# Reserved keyword
class = 10

# Contains a hyphen
user-name = "Doe"
```

# Assigning Values to Variables

## 1. Basic Assignment

```python
x = 5
y = 3.14
z = "Hi"
```

## 2. Dynamic Typing

Python is dynamically typed, so a variable can store different data types during execution.

```python
x = 10
x = "Now a string"
```

## 3. Assigning the Same Value

```python
a = b = c = 100
print(a, b, c)
```

**Output**

```text
100 100 100
```

## 4. Assigning Different Values

```python
x, y, z = 1, 2.5, "Python"
print(x, y, z)
```

**Output**

```text
1 2.5 Python
```

# Object References

Python variables store references to objects, not the actual values.

## Example

```python
x = 5
```

Python creates an object representing `5` and makes `x` reference it.

```python
y = x
```

Both `x` and `y` now reference the same object (`5`).

```python
x = "Geeks"
```

A new string object is created and `x` references it, while `y` still references `5`.

```python
y = "Computer"
```

Now `y` references a new string object as well.

> When a variable is reassigned, it points to a new object. Unreferenced objects become eligible for garbage collection.

---

# Understanding Variable Reassignment

```python
x = 1
y = x

y = y + 1

print(x)
print(y)
```

**Output**

```text
1
2
```

### Explanation

- Initially, both `x` and `y` reference the object `1`.
- After `y = y + 1`, `y` references a new object `2`.
- `x` continues to reference `1`.

---

# Deleting a Variable

Use the `del` keyword to delete a variable.

```python
x = 10
del x

print(x)
```

**Output**

```text
NameError: name 'x' is not defined
```

### Explanation

After `del x`, the variable no longer exists and cannot be accessed.

# Practical Examples

## Swapping Two Variables

```python
a, b = 5, 10
a, b = b, a

print(a, b)
```

**Output**

```text
10 5
```

## Counting Characters in a String

```python
word = "Python"
length = len(word)

print("Length of the word:", length)
```

**Output**

```text
Length of the word: 6
```

---

# Key Takeaways

- Variables are created when a value is assigned.
- Python uses dynamic typing.
- Variables store references to objects.
- Multiple assignment is supported.
- Variables can be swapped without a temporary variable.
- `del` removes a variable reference.
- Variable names must follow Python naming rules.
