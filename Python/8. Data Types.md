
## What are Data Types?

Data types define the type of value stored in a variable and determine the operations that can be performed on it.

### Why are Data Types Important?

- Help Python store and process data efficiently.
- Ensure only valid operations are performed on compatible data.

---

## Example

```python
x = 50
x = 60.5
x = "Hello World"
x = ["geeks", "for", "geeks"]
x = ("geeks", "for", "geeks")
```

A variable can hold different data types at different times.

---

# 1. Numeric Data Types

Used to store numbers.

| Type | Description | Example |
|--------|-------------|---------|
| `int` | Whole numbers | `5`, `-10` |
| `float` | Decimal numbers | `5.0`, `3.14` |
| `complex` | Real + Imaginary numbers | `2+4j` |

### Example

```python
a = 5
b = 5.0
c = 2 + 4j

print(type(a))
print(type(b))
print(type(c))
```

**Output**

```python
<class 'int'>
<class 'float'>
<class 'complex'>
```

---

# 2. Sequence Data Types

A sequence is an ordered collection of items.

## 2.1 String (`str`)

Stores text data.

### Example

```python
s = "Welcome to the Geeks World"

print(s)
print(type(s))

print(s[1])   # Indexing
print(s[-1])  # Last character
```

**Output**

```python
Welcome to the Geeks World
<class 'str'>
e
d
```

### Key Points

- Created using single, double, or triple quotes.
- Supports indexing.
- Immutable (cannot be changed).

---

## 2.2 List (`list`)

Ordered and mutable collection.

### Example

```python
a = [1, 2, 3]

b = ["Geeks", "For", "Geeks", 4, 5]

print(b[3])
print(b[-3])
```

**Output**

```python
4
Geeks
```

### Key Points

- Ordered.
- Mutable (can be modified).
- Can store different data types.

---

## 2.3 Tuple (`tuple`)

Ordered and immutable collection.

### Example

```python
t1 = (1,)
print(type(t1))

t2 = ('Geeks', 'For', 'Geeks', 1, 2)

print(t2[3])
print(t2[-3])
```

**Output**

```python
<class 'tuple'>
1
Geeks
```

### Key Points

- Ordered.
- Immutable (cannot be modified).
- Supports indexing.

### Single Element Tuple

```python
t = (1,)
```

> A comma is required, otherwise Python treats it as a normal value.

# 3. Boolean Data Type (`bool`)

Represents logical values.

### Values

```python
True
False
```

### Example

```python
print(type(True))
print(type(False))
```

**Output**

```python
<class 'bool'>
<class 'bool'>
```

---

## Truthy and Falsy Values

Values that behave like `True` or `False` in conditions.

### Example

```python
if 1:
    print("1 is truthy")

if not 0:
    print("0 is falsy")
```

**Output**

```python
1 is truthy
0 is falsy
```

### Common Falsy Values

```python
0
0.0
''
[]
{}
set()
None
False
```

Everything else is generally Truthy.

---

# 4. Set Data Type (`set`)

Unordered collection of unique elements.

### Example

```python
s1 = {"a", "a", "b", "c", "b"}
print(s1)

s2 = {"Geeks", "For", "Geeks"}

for i in s2:
    print(i)
```

**Output**

```python
{'b', 'a', 'c'}
Geeks
For
```

### Key Points

- Unordered.
- Mutable.
- Stores unique values only.
- No indexing support.

> Order may change each time the program runs.

---

# 5. Dictionary Data Type (`dict`)

Stores data as key-value pairs.

### Example

```python
d = {
    1: 'Geeks',
    2: 'For',
    3: 'Geeks'
}

print(d[1])
print(d.get(2))
```

**Output**

```python
Geeks
For
```

### Key Points

- Stores data in `key : value` format.
- Keys must be unique.
- Access values using keys.
- Keys are case-sensitive.

Example:

```python
d = {
    "Name": "Alice",
    "name": "Bob"
}
```

Here, `"Name"` and `"name"` are different keys.

# Quick Summary

| Data Type | Example | Ordered | Mutable |
|------------|----------|----------|----------|
| `int` | `5` | ❌ | ❌ |
| `float` | `3.14` | ❌ | ❌ |
| `complex` | `2+4j` | ❌ | ❌ |
| `str` | `"Hello"` | ✅ | ❌ |
| `list` | `[1, 2, 3]` | ✅ | ✅ |
| `tuple` | `(1, 2, 3)` | ✅ | ❌ |
| `bool` | `True` | ❌ | ❌ |
| `set` | `{1, 2, 3}` | ❌ | ✅ |
| `dict` | `{"a": 1}` | ✅* | ✅ |

> *Dictionaries preserve insertion order in Python 3.7+.

# Memory Trick

- **String** → Text
- **List** → Ordered & Editable
- **Tuple** → Ordered & Fixed
- **Set** → Unique Values
- **Dictionary** → Key → Value
- **Boolean** → True / False
- **Numeric** → int, float, complex
