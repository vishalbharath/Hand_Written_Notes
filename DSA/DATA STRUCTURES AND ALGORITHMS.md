-   **Data Structure (DS)**: A way to store and organize data so it can be used efficiently.  
    _Examples_: Arrays, Linked Lists, Trees, Graphs, Stacks, Queues, Hash Tables.
    
- **Algorithm**: A step-by-step procedure or formula for solving a problem.  
    _Examples_: Sorting (QuickSort, MergeSort), Searching (Binary Search), Traversals (BFS, DFS).

### **Searching Algorithms**

- **Linear Search** – O(n)
- **Binary Search** – O(log n) (on sorted arrays)

### **Recursion & Backtracking**

- Factorial, Fibonacci (Recursion)
- N-Queens, Maze problems (Backtracking)

### **Divide and Conquer**

- Merge Sort, Quick Sort, Binary Search

###  **Dynamic Programming (DP)**

- Memoization + Recursion
- Examples: 0/1 Knapsack, Longest Common Subsequence

### **Greedy Algorithms**

- Locally optimal choices
- Examples: Activity Selection, Huffman Coding

###  **Graph Algorithms**

- BFS & DFS (Traversal)
- Dijkstra’s (Shortest Path, O(V + E log V))
- Floyd-Warshall (All-Pairs Shortest Path)
- Kruskal’s & Prim’s (Minimum Spanning Tree)
