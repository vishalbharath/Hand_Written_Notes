- ****Tree data structure**** is a hierarchical structure that is used to represent and organize data in the form of parent child relationship.

![[Pasted image 20250813211714.png]]

- **Root** → The topmost node (no parent).
- **Parent & Child** → Nodes directly connected one level apart.
- **Leaf** → Node with no children.
- **Height** → Number of edges on the longest path from root to leaf.
- **Depth** → Distance from root to a node.

- Unlike arrays or linked lists, trees are **non-linear** and allow **hierarchical relationships**.

## **Types of Trees**

- **General Tree** – Any number of children.
- **Binary Tree** – At most two children per node.
- **Full Binary Tree** – Every node has 0 or 2 children.
- **Complete Binary Tree** – All levels filled except possibly last, filled left to right.
- **Perfect Binary Tree** – All internal nodes have 2 children and all leaves are at the same level.
- **Binary Search Tree (BST)** – Left child < Parent < Right child.
- **AVL Tree / Red-Black Tree** – Self-balancing trees.
