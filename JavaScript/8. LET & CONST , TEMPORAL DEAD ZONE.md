- These are in the Temporal Dead zone

> WHENEVER WE TRY TO ACCESS AN ELEMENT IN AN TEMPORAL DEAD ZONE IT THROWS AN REFERENCE ERROR

### Let

`let` is a **block-scoped** variable declaration introduced in **ES6 (ECMAScript 2015)**.  
Unlike `var`, which is **function-scoped**, `let` only exists within the **block `{}`** it’s declared in.

### Key Properties of `let`

| Feature            | Description                                      |
| ------------------ | ------------------------------------------------ |
| Scope              | Block-scoped (`{}`)                              |
| Re-declaration     | Not allowed in the same scope                    |
| Re-assignment      | Allowed                                          |
| Hoisting           | Hoisted, but **not initialized** (exists in TDZ) |
| Temporal Dead Zone |  Exists until initialization                     |
```javascript

{
  let x = 10;
  console.log(x); //  10
}
console.log(x); //  ReferenceError: x is not defined


```

Here, `x` is only accessible inside the block `{}` — this is **block scoping**.

Example with TDZ (Temporal Dead Zone):

```javascript


console.log(a); //  ReferenceError (TDZ)
let a = 5;
console.log(a); //  5


```

**Explanation:**
- The variable `a` is **hoisted**, but it’s **not initialized**.
- Between the **start of the block** and the **line of initialization**, `a` is in the **Temporal Dead Zone** (TDZ).
- Accessing it before initialization throws a **ReferenceError**.



### Const

`const` is also **block-scoped** like `let`, but it creates a **read-only (immutable) reference** to a value.

### Key Properties of `const`

| Feature            | Description                                      |
| ------------------ | ------------------------------------------------ |
| Scope              | Block-scoped                                     |
| Re-declaration     | Not allowed                                      |
| Re-assignment      | Not allowed                                      |
| Hoisting           | Hoisted, but **not initialized** (exists in TDZ) |
| Temporal Dead Zone |  Exists until initialization                     |

```javascript


const PI = 3.14;
console.log(PI); //  3.14
PI = 3.14159;    //  TypeError: Assignment to constant variable.


```

#### `const` with Objects and Arrays
Even though you can’t reassign the variable,  
you **can modify the contents** of objects or arrays (because the reference remains the same).

```javascript

const person = { name: "Vishal", age: 21 };
person.age = 22;        //  allowed
console.log(person);    // { name: "Vishal", age: 22 }

person = { name: "Bharath" }; //  TypeError


```


### Temporal Dead Zone (TDZ)


The **Temporal Dead Zone** is the time between:
1. The variable is **hoisted** to the top of its scope, and
2. The variable is **initialized with a value**.

During this zone, the variable exists but **cannot be accessed** — doing so throws a **ReferenceError**.

```javascript

{
  // TDZ starts here
  console.log(num); //  ReferenceError (num is in TDZ)
  
  let num = 10; // TDZ ends here
  console.log(num); //  10
}


```


##### visualization of TDZ Timeline

```scss

Code Block Execution
│
├── let num declared (hoisted but uninitialized)
│     ↑
│     │  ← Temporal Dead Zone (cannot access num)
│     │
│  console.log(num) ❌ ReferenceError
│
└── num initialized (TDZ ends)
    console.log(num) ✅ works fine

```


##### Another Example (with function):

```javascript

function demo() {
  console.log(a); //  ReferenceError
  let a = 5;
}
demo();


```

`a` is hoisted, but remains in the TDZ until the declaration line.


##### Real World Example

```javascript

function example() {
  console.log(x); //  undefined (var hoisted and initialized)
   console.log(y); //  ReferenceError (TDZ)
   console.log(z); //  ReferenceError (TDZ)

  var x = 10;
  let y = 20;
  const z = 30;

  console.log(x, y, z); // 10 20 30
}
example();



```



### TYPES OF ERRORS IN JAVASCRIPT

## QUICK COMPARISON TABLE

|Error Type|When It Occurs|Example|Common Cause|Fix|
|---|---|---|---|---|
|**SyntaxError**|During parsing (before execution)|`console.log("Hi"`|Invalid syntax|Correct syntax|
|**TypeError**|During runtime|`"abc" * 2`|Wrong data type operation|Convert or check types|
|**ReferenceError**|During runtime|`console.log(x)`|Variable not defined or in TDZ|Declare variable properly|
## Summary

| Error              | Phase        | Meaning                               | Example           |
| ------------------ | ------------ | ------------------------------------- | ----------------- |
| **SyntaxError**    | Compile-time | Invalid code structure                | `if (x {}`        |
| **TypeError**      | Runtime      | Wrong operation on wrong data type    | `null.toString()` |
| **ReferenceError** | Runtime      | Variable not declared or inaccessible | `console.log(y)`  |
