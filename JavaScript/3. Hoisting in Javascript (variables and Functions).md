### Hoisting 

- Hoisting in JavaScript is a **default behavior of the JavaScript interpreter** where variable and function declarations are moved ("hoisted") to the **top of their scope** (global or function scope) during the **compilation phase** (before code execution).
- But only **declarations** are hoisted, **not initializations**.

Example of *Variable Hoisting*

```javascript
console.log(a); // undefined (not error, because of hoisting)
var a = 10;


//Behind the scenes, JS treats it like:

var a;         // declaration hoisted
console.log(a); // undefined
a = 10;        // initialization stays in place

```

Example of *Function Hoisting*
```javascript

//Function Declatation
sayHello(); // Works fine
function sayHello() {
  console.log("Hello!");
}
 Function declarations are fully hoisted, meaning both their name and definition are available at the top.
-------------------------------

// Function Expression
sayHi(); // TypeError: sayHi is not a function
var sayHi = function() {
  console.log("Hi!");
};

Only the `var sayHi;` part is hoisted (undefined), not the function itself.

```
