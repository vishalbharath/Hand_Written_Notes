
- Everything in JavaScript happens inside an *Execution context*
- JavaScript is a **single-threaded, synchronous language** (by design) which means it can execute a Code one line at a time 
- but with the help of the **browser environment (Web APIs) or Node.js APIs**, it can handle **asynchronous tasks** like timers, HTTP requests, and events.

### Execution Context

- It is like a big box
- It has two components
- The *First Component* is Called as *Memory component* in which all the variables and functions are stored as *Key-value Pairs*
- This Memory component is also Known as *Variable Environment*
- The *Second Component* is called as the *Code Component* in which code is *Executed one line at a time* 
- This Code component is also Know as *Thread of Execution*
